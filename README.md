# ⛽ Tankomat

**Tankomat** ist eine smarte Web-App, die dir hilft, immer die günstigste Tankstelle in deiner Nähe zu finden.

---

## 🚀 Features

* ⛽ Anzeige aktueller Spritpreise
* 📍 Standortbasierte Suche
* 🗺️ Interaktive Karte mit Tankstellen
* 🧭 Navigation zur Tankstelle
* 💰 Automatische Hervorhebung des besten Preises
* 📱 Optimiert für Smartphone & Desktop
* ⭐ Favoriten speichern

---

## 🧠 Wie es funktioniert

Tankomat nutzt Standortdaten und aktuelle Preisinformationen, um dir die besten Tankstellen in deiner Umgebung anzuzeigen.

Einfach öffnen → vergleichen → sparen.

---

## 📱 Nutzung

1. Standort erlauben
2. Ergebnisse anzeigen lassen
3. Günstigste Tankstelle auswählen
4. Direkt zur Navigation starten

---

## 🛠️ Technologie

* HTML, CSS, JavaScript
* Leaflet (Kartenanzeige)
* API für Spritpreise
